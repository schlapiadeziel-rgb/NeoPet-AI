# NeoPet AI

NeoPet AI is a cross-platform AI desktop pet with a transparent always-on-top window, email OTP login, OpenAI-compatible API support, voice output, response-driven animations, local conversation memory, and AI-generated or imported pet artwork.

Windows is the first packaged and tested platform. The Electron project also contains macOS DMG and Linux AppImage targets for later platform-specific verification.
