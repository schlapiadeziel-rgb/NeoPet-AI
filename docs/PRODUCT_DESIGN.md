# NeoPet AI 产品与交互设计

## 产品定位

NeoPet AI 是双形态产品：电脑端是有动作、情绪、记忆和养成的长期桌面宠物；移动端 NeoAI 是帮助用户使用手机的 AI 工具工作台。两端共享可配置模型能力，但交互形态按设备场景分别设计。

## 参考产品带来的设计取舍

- Desktop Mate：学习角色停靠窗口、追随鼠标、缩到屏幕边缘和不打断工作的设计。
- Shimeji / Desktop Goose：学习随机行为、拖动反馈和“宠物自己有事做”的生命感。
- Open-LLM-VTuber：学习透明桌宠模式、语音打断、表情映射与本地运行能力。
- DesktopFriends：学习电脑与 Android 双端、模型自由配置和多设备连接。
- Live2DPet / Warashi：学习主动对话、长期记忆、屏幕感知和安装向导，但屏幕感知必须明确授权并默认关闭。

不复制第三方角色、美术、声音或受限制代码。电影和动画只能作为风格参考，生成结果必须保持原创或取得授权。

## 平台形态

### Windows / macOS / Linux

- 透明置顶宠物窗口，默认仅显示宠物。
- 默认宠物本体约 190 × 210 px，紧凑窗口约 300 × 360 px，只比小型桌宠略大，不占据主要工作区。
- 单击互动、双击聊天、右键设置、拖动移动。
- 可切换鼠标穿透，长时间闲置缩到屏幕边缘。
- 聊天、模型、记忆和角色管理在展开面板中完成。

### Android

- 对话为中心，提供会话历史、附件、语音、手机工具、模型中心和设置。
- 用户可在应用内按名称、大小和内存要求选择 GGUF 模型，下载后离线运行；也可切换 API 或局域网模型服务。
- 手机动作先显示确认卡；跨 App 点击和输入只有在用户手动开启无障碍服务后才可使用，敏感操作始终拦截。

### iOS / iPadOS

- PWA 提供对话、附件、语音、视频中心和 API/局域网模型配置。
- 受平台沙箱限制，不承诺 Android 原生本地推理或跨 App 自动操作。

### 通用移动端

- PWA 提供 Android、iOS、平板和移动浏览器的共同基础版本。
- 原生壳负责本地推理、模型下载和经过确认的系统动作；浏览器版自动隐藏不支持的能力。

## 手机工具协议

移动端 AI 输出 `reply` 和可选 `tool`。工具只允许打开设置、相机、闹钟、日历、地图、拨号编辑、短信编辑、分享、网页及受限跨 App 步骤。每次执行前都由用户确认；拨号和短信只预填，不直接拨出或发送。

## 隐私边界

- API 密钥不提交到仓库；桌面端使用系统安全存储，移动网页端仅保存到浏览器会话。
- 摄像头、麦克风和无障碍权限默认关闭，使用时逐项说明目的；不申请悬浮窗权限。
- 邮箱验证码正式发布时必须由服务端发送，客户端不能内置 SMTP 授权码。
